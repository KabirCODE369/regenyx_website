REGENYX AEROSPACE FINAL WEBSITE SETUP

Folder structure:
- index.html
- robots.txt
- sitemap.xml
- css/style.css
- js/main.js
- assets/images/favicon.png   <-- YOU MUST ADD THIS
- assets/images/regenyx-logo.png
- assets/videos/regenyx-space.mp4

IMPORTANT:
1. Put your existing regenyx-logo.png in assets/images/.
2. Put your existing regenyx-space.mp4 in assets/videos/.
3. Create a square favicon.png (recommended 192x192 PNG) and put it in assets/images/.
4. Upload the entire folder contents to the root of your GitHub Pages repository.
5. The canonical domain in these files is https://regenyx.space/. If your real primary domain is different, change canonical/OG/JSON-LD/sitemap/robots consistently.
6. The language menu provides English/French natively and Google Translate for the additional European languages plus Arabic and Persian.
